code-audit-paper

Audit academic papers — compare claims against actual code.

Given a paper title, this ZCode skill fetches the LaTeX source from arXiv, finds the corresponding repository on GitHub, and analyzes whether the paper's claims and experiments match the actual implementation.

Quick Start

# Install
git clone git@github.com:x2x5/code-audit-paper.git ~/.agents/skills/code-audit-paper

# Then in ZCode, type:
/code-audit-paper <arXiv ID or paper title>

# Or just say:
"Audit the paper 'Attention Is All You Need'"

What Gets Checked

🔁 Reproducibility

Dataset accessibility, pretrained weights, baseline implementations.

🧩 Method Consistency

Does the code match the paper's architecture description?

🔬 Experiment Details

Hyperparameters, preprocessing, evaluation — paper vs code.

📊 Code Coverage

Which experiments actually have corresponding code?

Run Standalone Scripts

# 1. Fetch LaTeX from arXiv
python3 scripts/fetch_arxiv.py "<title>" -o ./output

# 2. Find & clone code from GitHub
python3 scripts/fetch_code.py "<title>" -o ./output -l ./output/<name>/latex

# 3. Audit
python3 scripts/audit.py ./output/<name>/latex ./output/<name>/code \
    -o ./output/<name>/audit

Output

<paper_name>/             # abbreviation or first 6 words
├── latex/               # LaTeX source
├── code/                # GitHub code (if available)
├── audit/               # audit report
│   ├── analysis_report.md
│   ├── full_audit_report.md
│   └── method_vs_code.md
├── qa/                  # Q&A HTML pages
│   └── introduction.html
├── paper.json
└── repo.json

Design

  • No LaTeX? Stop. No PDF parsing.
  • No GitHub repo? Say so. Don't fake it.
  • Zero external deps. Python 3.6+ stdlib + git.
  • Agent judges. Scripts assist, agent reads LaTeX & code.
  • Reports in Chinese, Q&A pages in three-column format (EN · plain · ZH).

code-audit-paper

论文代码审计——对比论文声明与实际代码实现。

输入论文标题或 arXiv ID，自动去 arXiv 下载 LaTeX 源码，到 GitHub 找对应仓库，然后从 4 个维度审计论文有没有吹牛、有没有隐瞒、实验能不能复现。

快速开始

# 安装
git clone git@github.com:x2x5/code-audit-paper.git ~/.agents/skills/code-audit-paper

# 在 ZCode 中触发：
/code-audit-paper <arXiv ID 或论文标题>

# 或直接说：
"帮我审计一下 'Attention Is All You Need'"

审计维度

🔁 可复现性

数据集能获取吗？预训练权重有吗？baseline 真实现了还是只贴了数字？

🧩 方法一致性

论文描述的方法和代码里的实现是不是一回事？

🔬 实验细节

超参数、预处理、评估方式——论文说的和代码配置一致吗？

📊 代码覆盖率

论文做了哪些实验，哪些在代码里真的有对应实现？

直接跑脚本

# 1. 从 arXiv 下载 LaTeX
python3 scripts/fetch_arxiv.py "<论文标题>" -o ./output

# 2. 从 GitHub 获取代码
python3 scripts/fetch_code.py "<论文标题>" -o ./output -l ./output/<论文名>/latex

# 3. 执行审计
python3 scripts/audit.py ./output/<论文名>/latex ./output/<论文名>/code \
    -o ./output/<论文名>/audit

输出结构

<论文名>/             # 方法缩写或标题前6词
├── latex/            # LaTeX 源码
├── code/             # GitHub 代码（如有）
├── audit/            # 审计报告
│   ├── analysis_report.md
│   ├── full_audit_report.md
│   └── method_vs_code.md
├── qa/               # QA 问答网页
│   └── introduction.html
├── paper.json
└── repo.json

设计原则

  • 没有 LaTeX？ 停止，不解析 PDF。
  • 搜不到 GitHub？ 如实说，不硬找。
  • 零外部依赖，只要 Python 3.6+ 和 git。
  • 代理（agent）做判断，脚本只是辅助。
  • 报告用中文，问答页三栏对照（英 · 人话 · 中）。
