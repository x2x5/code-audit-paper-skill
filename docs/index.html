🔍 Audit Flow

Cheap model runs a full first-pass audit — smart model is an optional second opinion

⚡ Phase 1 · First-Pass Audit

Run with a cheap model
(e.g. DeepSeek Flash)

1 🔧 Environment Check
Check: python or python3? git? curl? Record the right commands for this system.
2 📥 Parse Input
Accept arXiv ID, paper title, or URL. Auto-detect paper and create a clean folder name.
3 📄 Download from arXiv
Fetch PDF + LaTeX source. The .tex files are key — they let us scan for GitHub links and parse claims.
✅ LaTeX → continue ❌ None → note in report
4 🔗 Find & Clone Code
Scan LaTeX for GitHub links. Identify the real code repo (skip datasets, deps). Clone and verify it has actual code.
✅ Has code → continue ❌ None → note in report
5 🧪 Automated Scan
Parse LaTeX claims, analyze code structure, cross-reference. Generates audit/audit_report.html scaffold.
6 🔬 Four-Dimension Audit
Read LaTeX and code. Check all four dimensions and write findings into audit_report.html.
🔁 Reproducibility Datasets, weights, baselines
🧩 Method Consistency Paper claims vs. code
🔬 Experiment Details Hyperparams, preprocessing
📊 Code Coverage Which experiments have code?
7 💬 Generate QA Pages
Translate the Introduction into a three-column HTML page (EN · plain · ZH). Each paragraph is a card.
qa/introduction.html · qa/method.html · …
✓ 📋 Save Handoff Prompt
Write a detailed handoff prompt to handoff_prompt.md — includes first-pass audit summary, all file paths, and a 5-task checklist for deeper re-audit.
✅ Phase 1 complete! Report is ready at audit/audit_report.html. Most users stop here.
🔍 OPTIONAL 🧠 Phase 2 · Deep Re-Audit

Only if you want a second opinion
with a smart model (e.g. DeepSeek Pro)

📋 Read handoff_prompt.md
Open the prompt file saved by Phase 1. It contains the full context: paper info, all file paths, the first-pass audit summary, and the 5 deep re-audit tasks.
📋 Copy the prompt content, paste it into a new session with a smart model.
🔍 Deep Re-Audit (5 Tasks)
Go deeper than Phase 1's analysis:
  1. Method deep-dive — re-examine every ⚠️, find missed details, spot hidden components
  2. Experiment verification — check every hyperparameter, every preprocessing step
  3. Full coverage sweep — list every experiment (incl. appendix), find code for each
  4. Claim-by-claim review — judge which claims are verifiable vs. vague
  5. Code quality assessment — readability, tests, reproducibility readiness
✓ Update Report & Done
Edit audit/audit_report.html with deeper findings. Mark revised conclusions with 🔍 深度重审： prefix. Final verdict updated.

🔍 审计流程

便宜模型跑完整首轮审计 — 聪明模型是可选的第二意见

⚡ 阶段一 · 首轮审计

用便宜模型跑
（如 DeepSeek Flash）

1 🔧 环境检查
检查 python 还是 python3？有没有 git？curl？记下正确的命令名。
2 📥 解析输入
接收 arXiv ID、论文标题或链接。自动识别论文，起一个干净的文件夹名。
3 📄 从 arXiv 下载
抓取 PDF + LaTeX 源码。.tex 文件是关键——用来扫描 GitHub 链接和解析声明。
✅ 有 LaTeX → 继续 ❌ 没有 → 报告中注明
4 🔗 查找并克隆代码
扫 LaTeX 找 GitHub 链接，判断哪个是真正的代码仓库（跳过数据集、依赖库）。克隆后确认有实际代码。
✅ 有代码 → 继续 ❌ 没有 → 报告中注明
5 🧪 自动扫描
解析 LaTeX 声明、分析代码结构、交叉比对。生成 audit/audit_report.html 脚手架报告。
6 🔬 四维度审计
读 LaTeX 和代码，检查四个维度，把发现写入 audit_report.html。
🔁 可复现性 数据集、权重、baseline
🧩 方法一致性 论文声明 vs. 代码
🔬 实验细节 超参数、预处理
📊 代码覆盖率 哪些实验有代码？
7 💬 生成 QA 页面
把引言翻译成三栏 HTML（英 · 人话 · 中）。每个自然段一张卡片。
qa/introduction.html · qa/method.html · …
✓ 📋 保存交接提示词
把详细的交接提示词写入 handoff_prompt.md——包含首轮审计摘要、所有文件路径、深度重审的 5 项任务清单。
✅ 阶段一完成！报告在 audit/audit_report.html，浏览器直接看。大多数用户到这里就停了。
🔍 可选 🧠 阶段二 · 深度重审

只有当你想要第二意见时才跑
用聪明模型（如 DeepSeek Pro）

📋 读取 handoff_prompt.md
打开阶段一保存的提示词文件。里面有完整上下文：论文信息、所有文件路径、首轮审计摘要、深度重审的 5 项任务。
📋 复制提示词内容，粘贴到新会话窗口（已切换聪明模型）。
🔍 深度重审（5 项任务）
比首轮审计挖得更深：
  1. 方法深挖 — 重审每个 ⚠️，找遗漏细节，发现隐藏组件
  2. 实验逐项核实 — 检查每个超参数、每个预处理步骤
  3. 全覆盖扫描 — 列出每个实验（含附录），逐个找代码
  4. 逐条声明验证 — 判断每条声明是可验证的、还是模糊的
  5. 代码质量评估 — 可读性、测试、复现就绪度
✓ 更新报告 · 完成
把更深度的发现写入 audit/audit_report.html。修改过的结论加 🔍 深度重审： 前缀。更新最终总结。
