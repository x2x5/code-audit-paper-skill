🔍 Audit Flow

Two phases, two models — cheap for prep, smart for analysis

⚡ Phase 1 · Preparation

Run with a cheap model
(e.g. DeepSeek Flash)

1 🔧 Environment Check
Check what's available: python or python3? git? curl? Record the correct commands — different systems name them differently.
2 📥 Parse Input
Accept arXiv ID, paper title, or full URL. Automatically figure out the paper and create a clean folder name.
3 📄 Download from arXiv
Fetch PDF + LaTeX source bundle via arXiv API. The .tex files are key — without them we can't scan for GitHub links or parse claims.
✅ LaTeX → continue ❌ No LaTeX → skip to handoff
4 🔗 Find & Clone Code
Scan LaTeX for GitHub links. Identify the actual code repo (skip datasets, dependencies). If not found, search GitHub by title. Clone and verify it has real code.
✅ Has code → continue ❌ No code → skip to handoff
5 🧪 Run Automated Audit
Parse LaTeX claims, analyze code structure, cross-reference. Generates audit/audit_report.html — a scaffold with paper overview, code stats, and placeholder areas for the deep audit.
6 📋 Output Handoff Prompt
Phase 1 ends here. Output a self-contained prompt with all paths, stats, and a 7-step task list for Phase 2. Do not do any deep analysis.
📋 User copies prompt → opens new session → switches to smart model → pastes → Phase 2 begins.
🧠 Phase 2 · Deep Analysis

Run with a smart model
(e.g. DeepSeek Pro)

7 📖 Read All Materials
Open audit_report.html to see the automated scan. Read the LaTeX source (abstract, intro, method, experiments). Browse the code structure and key files.
🎯 Everything is already downloaded — you start with full context.
8 🔬 Four-Dimension Deep Audit
Go through each dimension and write findings into audit_report.html (placeholder sections are ready).
🔁 Reproducibility Datasets, weights, baselines
🧩 Method Consistency Paper claims vs. code
🔬 Experiment Details Hyperparams, preprocessing
📊 Code Coverage Which experiments have code?
9 💬 Generate QA Pages
Translate the Introduction into a three-column HTML page: English original · plain-language explanation · Chinese translation. Each paragraph is a card.
qa/introduction.html · qa/method.html · …
✓ Audit Complete
Complete audit_report.html with all four dimensions filled in, plus QA pages. All self-contained HTML — open in any browser.

🔍 审计流程

两阶段、两模型 — 便宜的做体力活，聪明的做分析

⚡ 阶段一 · 准备

用便宜模型跑
（如 DeepSeek Flash）

1 🔧 环境检查
检查环境里的命令：是 python 还是 python3？有没有 git？有没有 curl？不同系统命令名不一样，先搞清楚，后面不报错。
2 📥 解析输入
接收 arXiv ID、论文标题或完整链接。自动识别是哪篇论文，起一个干净易读的文件夹名。
3 📄 从 arXiv 下载
通过 arXiv API 抓取 PDF + LaTeX 源码包。.tex 文件是关键——没有它就无法扫描 GitHub 链接、无法解析声明。
✅ 有 LaTeX → 继续 ❌ 没有 → 跳到交接提示词
4 🔗 查找并克隆代码
扫 LaTeX 找 GitHub 链接，判断哪个是真正的代码仓库（跳过数据集、依赖库）。找不到就去 GitHub 按标题搜。克隆后确认里面有实际代码。
✅ 有代码 → 继续 ❌ 没有 → 跳到交接提示词
5 🧪 运行自动审计脚本
解析 LaTeX 声明、分析代码结构、交叉比对。生成 audit/audit_report.html——一份脚手架报告，含论文概览、代码统计和留给阶段二的占位区域。
6 📋 输出交接提示词
阶段一到此结束。输出一段自包含的交接提示词，含所有路径、统计和阶段二的 7 步任务清单。不要做任何深度分析。
📋 用户复制提示词 → 开新窗口 → 切聪明模型 → 粘贴 → 阶段二接上。
🧠 阶段二 · 深度分析

用聪明模型跑
（如 DeepSeek Pro）

7 📖 阅读所有材料
打开 audit_report.html 看自动扫描结果。通读 LaTeX 源码（摘要、引言、方法、实验），浏览代码结构和关键文件。
🎯 所有文件都已下载好，一上来就有完整上下文。
8 🔬 四维度深度审计
逐维度检查，把发现写入 audit_report.html（占位区域已就绪）。
🔁 可复现性 数据集、权重、baseline
🧩 方法一致性 论文声明 vs. 代码
🔬 实验细节 超参数、预处理
📊 代码覆盖率 哪些实验有代码？
9 💬 生成 QA 解读页
把引言翻译成三栏 HTML 页面：英文原文 · 人话解释 · 中文翻译。每个自然段一张卡片。
qa/introduction.html · qa/method.html · …
✓ 审计完成
完整的 audit_report.html（四个维度已填好）+ QA 解读页面。全部自包含 HTML，浏览器直接打开。
