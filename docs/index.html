📋 code-audit-paper

🔍 Audit Flow

code-audit-paper · from paper title to audit report

1 Input
arXiv ID  ·  Paper title  ·  Full URL
/code-audit-paper <query>
2 Download LaTeX from arXiv
Fetch the LaTeX source bundle via the arXiv API.
fetch_arxiv.py "<query>" -o <base_dir>
✅ Available
📄 LaTeX saved
Source extracted to latex/
❌ Not available
⛔ Stop
arXiv has no LaTeX source. PDF-only papers cannot be audited.
3 Find Code Repository
Scan LaTeX for GitHub URLs, or search GitHub by title.
fetch_code.py "<query>" -o <base_dir> --latex-dir <latex>
✅ Repo found
📦 Cloned
Code saved to code/
✅ Has code
▶ Proceed
❌ Empty repo
⛔ Stop
README-only, no source code
❌ Not found
⛔ Stop
Ask user for a URL, or report that code is unavailable.
4 Run Audit
Parse LaTeX claims, analyze code, generate report.
audit.py <latex> <code> -o <audit>
▼ 4 Audit Dimensions ▼
🔁
Reproducibility
Dataset, weights, baselines
🧩
Method Consistency
Paper vs code architecture
🔬
Experiment Details
Hyperparams, preprocessing
📊
Code Coverage
Which experiments have code?
5 Generate Q&A Pages
Default: translate Introduction into three-column HTML (EN · plain · ZH). More pages for follow-up questions.
qa/introduction.html  ·  qa/experiments.html  ·  …

🔍 审计流程

code-audit-paper · 从论文标题到审计报告

1 输入
arXiv ID · 论文标题 · 完整 URL
/code-audit-paper <查询>
2 下载 LaTeX 源码
通过 arXiv API 获取 LaTeX 源码包。
fetch_arxiv.py "<查询>" -o <输出目录>
✅ 有 LaTeX
📄 源码已保存
解压到 latex/ 目录
❌ 没有 LaTeX
⛔ 停止
arXiv 只有 PDF，没有 LaTeX 源码。无法审计。
3 查找代码仓库
扫描 LaTeX 找 GitHub 链接，或按标题搜 GitHub。
fetch_code.py "<查询>" -o <输出> --latex-dir <latex>
✅ 找到仓库
📦 已克隆
代码保存到 code/
✅ 有代码
▶ 继续
❌ 空仓库
⛔ 停止
只有 README，无实际代码
❌ 没找到
⛔ 停止
问用户有没有仓库 URL，或如实报告代码不可用。
4 执行审计
解析 LaTeX 声明、分析代码、生成审计报告。
audit.py <latex> <code> -o <audit>
▼ 四个审计维度 ▼
🔁
可复现性
数据集、权重、baseline
🧩
方法一致性
论文 vs 代码架构
🔬
实验细节
超参数、预处理
📊
代码覆盖率
哪些实验有代码？
5 生成 QA 问答页
默认翻译引言为三栏 HTML（英 · 人话 · 中）。后续问题继续添加。
qa/introduction.html · qa/experiments.html · …
